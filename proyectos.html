Una muestra de lo que he construido para clientes y proyectos propios.

Especialidad

Facturación electrónica · Integración

Corrección y transmisión externa de facturas electrónicas

Herramienta independiente que toma los datos ya registrados de las facturas, permite corregir lo que esté mal (cliente, impuestos, numeración) y los transmite al sistema de facturación electrónica sin depender del programa de ventas. Resuelve el día en que el software del negocio no transmite, falla o le rechazan documentos.

  • Facturación electrónica
  • DIAN
  • Bases de datos
  • Integración

Shopify · App + tema

Migración masiva de productos y descuentos por volumen en Shopify

App para una tienda mayorista multimarca: carga y migración masiva de productos, y una Shopify Function que aplica descuentos escalonados según la cantidad comprada. Incluye personalización del tema de la tienda.

  • Shopify CLI
  • Functions
  • Liquid
  • Prisma

Automatización · Multi-sede

Consolidación automática de inventarios en varias sedes

Sistema que se conecta al SQL Server de cada sede, cruza el inventario físico contra el del sistema, calcula diferencias, permite justificarlas y genera reportes Excel y dashboards con indicadores.

  • Node.js
  • TypeScript
  • SQL Server
  • React
  • ExcelJS

E-commerce · Panel admin

Tienda online de videojuegos con panel administrativo

Catálogo, carrito, checkout y un panel para administrar productos, categorías, pedidos y configuración sin tocar código. Diseño arcade-retro adaptado a la identidad del negocio.

  • Vite
  • Tailwind
  • PHP
  • MySQL

Sistema interno · Contabilidad

Sistema contable con dashboard e informes en PDF

Aplicación web para llevar la contabilidad de un negocio: registros, reportes en PDF y un dashboard interactivo con la información clave del día a día.

Catálogo web · Pequeño negocio

Catálogo web para una tienda de decoración y regalos

Página y catálogo para un negocio de plantas, decoración y regalos hechos a mano, con panel administrativo para editar productos desde el celular. Publicada sin costo de hosting.

  • Vercel
  • Serverless

Para quien transmite con una sola pantalla: recorta la zona de comentarios del directo y la muestra en una ventana siempre visible que el mouse atraviesa, para leer el chat sin salir del juego.
